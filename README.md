# HACKRONIX Chat

A secure real-time chat application with file sharing capabilities, built with Node.js, Express, and Socket.IO.

## Features

- Real-time messaging
- User authentication (no signup required)
- File sharing (images and documents)
- Emoji support
- Modern dark theme UI
- Responsive design for mobile and desktop
- Direct IP-based communication
